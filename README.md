# Corporate ESG — Impact Dashboard

> Interactive dashboard prototype for corporate ESG management, featuring maturity indicators, UN SDG targets and audited impact partnerships.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Corporate sustainability (ESG)

Interactive dashboard prototype for corporate ESG management, featuring maturity indicators, UN SDG targets and audited impact partnerships.

**Highlights**

- ESG maturity scoring with compliance alerts
- UN Sustainable Development Goal tracking
- Directory of audited third-sector partnerships

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
